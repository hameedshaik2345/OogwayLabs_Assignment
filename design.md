# Design Document

## 1. UI/UX Principles
- **Clarity over Clutter:** The interface is split into two clean panels. Chat on the left, Artifacts on the right.
- **Immediate Feedback:** Typing indicators inform the user when the LLM is generating a response.
- **Seamless Flow:** The user shouldn't have to switch tabs. Code/HTML generated by the LLM is automatically extracted and rendered in the Artifact Viewer.

## 2. Information Architecture
- **Left Panel (Chat):** Scrollable message history. Differentiates user messages (blue bubbles) from assistant messages (white bubbles).
- **Right Panel (Artifact Viewer):** A dark-themed header with a white sandbox area for rendering outputs like Markdown or HTML.

## 3. Responsive Behavior
- Currently optimized for desktop (side-by-side).
- On smaller screens, the layout could break down into a stacked view (Chat on top, Artifact on bottom), though the primary use-case for this iteration is desktop.

## 4. Accessibility Considerations
- High contrast colors (blue, black, white) for text readability.
- Semantic HTML used in the chat layout.
- Proper focus states for the chat input field and submit button.
